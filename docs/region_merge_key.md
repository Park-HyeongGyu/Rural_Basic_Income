# Region Merge Key

`src/rural_basic_income/worker/resources/region_merge_key.csv`는 인구, 세대, 이동자 데이터를 결합할 때 사용할 최종 지역 기준표이다.

## 기준

- 최종 지역 universe는 `raw.mover`에 존재하는 시군구 지역만 사용한다.
- `raw.household`, `raw.population`에만 있고 `raw.mover`에 없는 지역은 이 파일에 넣지 않는다.
- 이 파일은 테이블별 전처리 규칙을 담지 않는다. 각 raw table을 이 기준에 맞추는 작업은 이후 SQL에서 테이블별로 처리한다.

## 컬럼

| 컬럼 | 설명 |
| --- | --- |
| `region_sido` | 축약 시도명 |
| `region_sigungu` | 최종 결합용 시군구명 |
| `is_gun` | `region_sigungu`가 `군`으로 끝나면 `1`, 아니면 `0` |

## 지역명

`region_sigungu`는 `raw.mover`의 시군구명을 기본으로 사용한다.

다만 다음 표기는 결합 안정성을 위해 정리한다.

| 원자료 표기 | 사용 표기 |
| --- | --- |
| 세종특별자치시 | 세종시 |
| 창원시(통합) | 창원시 |

원자료 지역명 안의 공백은 제거한다. 예를 들어 `남  구`는 `남구`로 사용한다.

## 포함 범위

현재 생성된 `region_merge_key.csv`는 229개 지역을 포함한다. 이 중 `is_gun = 1`인 군 지역은 82개이다.

광역시의 일반 구는 그대로 유지한다. 예를 들어 서울 중구, 부산 중구, 대구 남구, 광주 남구, 울산 남구는 각각 다른 `region_sido`와 함께 별도 지역으로 남긴다.

## 후속 SQL 작업

이 파일은 최종 결합 기준만 제공한다. 다음 작업은 각 raw table을 `region_merge_key.csv`에 맞춰 정리하는 SQL을 테이블별로 작성하는 것이다.

예를 들어 `raw.household`나 `raw.population`에 `raw.mover`보다 더 세분화된 하위 구 또는 출장소가 있을 수 있다. 이런 경우 부모 지역을 사용할지, 하위 지역을 합산할지, 삭제할지는 각 테이블의 SQL 정제 단계에서 명시적으로 처리한다.
